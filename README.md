# AWS Student Community Day

React, TypeScript, GSAP, and Vite implementation of the website designs in the Figma page `00/ Final`.

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and build the production site. TypeScript also checks for unused locals and parameters. Run `npm run preview` to preview that build.

The site plays the intro once per browser tab before opening the requested page. Visit `/loading` to replay it. **Enter the day** skips the animation.

The first visit in each browser tab starts with `LoadingFlight` on desktop and mobile, then opens the originally requested page or section. Session storage remembers completion so later navigation and refreshes skip the intro. `/loading` remains available to replay it. The hero's pixel plane delivers a paper AWS banner from the right with stitched ropes. After the banner settles, the plane releases it and exits left. The banner's folded lower panel opens to reveal the original orange smile; its paper backing then fades, leaving the complete AWS mark. Delivery, opening, and the final logo hold take 2.8 seconds. `LoadingTransition` then sweeps a white dithered cloud from left to right over 900 ms, changing pages while the viewport is covered and clearing to reveal the hero. The Enter the day link uses the same transition. Automatic navigation replaces the loading page's history entry so Back does not replay the intro. The flight pauses while the tab is hidden and adapts its entrance and exit to the viewport. Reduced motion skips both animations and opens the requested page immediately.

The implemented pages are `/`, `/technical`, `/non-technical`, `/registration`, `/faq`, and `/404`. Unknown paths use the 404 design. Internal links and section navigation work without a page reload.
